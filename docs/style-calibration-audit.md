# Style calibration audit

## Reference alignment

The expanded calibration map contains 420 styles. Its 420 style headings match the app's 420 style definitions by genre and style name. The references and their sonic notes are now carried into the style picker. The map provides a named recording for 392 styles; the remaining 28 use a traditional ensemble, repertoire, or broader scene as the source anchor, and the UI labels those credits without inventing a track title.

The picker summary shows the first three style-specific sonic cues. The detail card includes the full reference credit, up to six calibration cues, the authored instrument palette, and a plain-language mix readout for room, low end, stereo width, and brightness. These references guide arrangement and production choices; they are not transcription targets.

## Instrument mapping

The 188-entry instrument catalog already covers the defining instruments in this map, including tres, cavaquinho, requinto, jarana, vihuela, guitarrón, bajo sexto, bandoneon, marimba de chonta, log drum, tabla, tanpura, oud, qanun, guzheng, shamisen, and gayageum. Style palettes should keep using these shared physical instrument IDs. Flamenco, calypso, and other guitar idioms belong in the guitar's setup, technique, articulation, and role mappings rather than separate genre-named guitars.

### Future instrument candidates

| Candidate | Useful context | Recommendation |
| --- | --- | --- |
| Marímbula | Cuban changüí and related son-derived bass roles | Consider a distinct low-register plucked lamellophone if those styles become a first-class target. It has a different excitation and decay from both upright and electric bass. |
| Viola caipira setup | Brazilian paired-course guitar traditions | Add as a guitar variant with its tuning and paired-string behavior if Brazilian country/sertanejo becomes a target. Do not add a second generic guitar instrument. |
| 808 bass/drum voice | Trap and modern reggaeton production | Keep as synth/bass patch and drum-kit component behavior, not a top-level instrument identity. |

These are follow-up candidates, not requirements for the current map. The current catalog already has close, usable instruments for the supplied references, so this pass adds no redundant instrument IDs.

## Calibration dimensions to preserve

Style selection should continue to resolve its own tempo and meter, groove cells, chord material, section personnel, instrument techniques, and dynamic mix contract. When revising a style, use the reference cues to tune those existing dimensions first: pulse and accents, bass-to-percussion relationship, lead phrasing, ensemble density, sectional changes, transient shape, low-end weight, width, and ambience. Add a new instrument only when its physical source changes the playable behavior in a meaningful way.
